# Decision Log — Winnow PRD
*Created 2026-05-22*

- **Product name**: Winnow (winnowing = separating grain from chaff by wind; wordplay on RICE scoring)
- **Key constraint**: The LLM/research agent never assigns a score. It presents evidence, data, and a structured report. The human PM always puts the number down.
- **Effort treatment**: Winnow does not research Effort externally but speculates on how the item would be built (broad description), helping the user reason about sizing. User assigns the score.
- **Context probe**: After the user defines the scoring category (e.g. "features"), Winnow asks "Features for what?" to ground downstream research.
- **Review loop**: The "does anything look off" stage is interactive. Weight changes are offered as an option at least once. User can adjust scores and re-rank before finalizing.
- **Low-confidence guardrail**: If all items have low confidence scores across the board, Winnow warns the user this looks like a gut-feel exercise and recommends more research rather than proceeding blindly.
- **Finalized**: 2026-05-22. PRD passed rubric review (1 critical, 2 high, 4 medium, 5 low — all resolved), structural polish, and prose review. Status set to final.

# Decision Log — sprint-runner

## Session 2026-05-21 (build)

**Classification:** Simple Workflow — all stages fit inline in SKILL.md (~110 lines).

**Architecture:** Parent orchestrator spawns a sub-agent per story via the Task tool. Each sub-agent gets the full dev→review→fix→defer workflow in a fresh context. Parent only reads sprint-status.yaml and collects results. This prevents context bloat when processing many stories.

**Headless mode:** Supported. Requires epic specification. Skips all confirmations.

**Parallelism:** Supports `--max-parallel N` (default 1, sequential). When N > 1, launches up to N sub-agents concurrently, batching as each finishes.

**Scope:** Operates on sprint-status.yaml. No hardcoded epic — always prompts (interactive) or requires specification (headless).

**Deferral criteria:** Findings are deferred (not fixed) when they involve architectural decisions OR impact multiple stories. Applied by sub-agents within their isolated context.

**Fix loop depth:** Two passes max per story, enforced by sub-agents.

**Customization:** None. Shipping fixed.

**Decision-Log Workspace:** Not applied.

**Output artifact:** `deferred-decisions.md` written to `{project-root}/docs/_bmad-output/implementation-artifacts/`.

**Name:** `sprint-runner` — standalone, kebab-case.

**Description trigger:** Explicit invocation via "run sprint" or "execute sprint stories."

## Session 2026-05-22 (diff pollution fix)

**Commit-after-session:** Added Phase A.5 (commit after implementation) and Phase C.5 (commit after fix pass). Each creates an atomic git commit scoped to the story's `files_changed`. This prevents diff contamination between stories by ensuring every pipeline transition is a clean checkpoint. Failed commits halt the pipeline.

**Architecture review gate:** Added Phase D.5 between Verify and Mark done. Triggers when (a) `findings_remaining` contains architectural items or (b) the story touches shared mutable state, timers, resource limits, concurrency, caching, unbounded collections, or cross-cutting concerns. Spawns a dedicated architecture-review sub-agent that checks five structural risk categories. If action is required, findings are appended as deferred decisions and the story stays in `review` for human intervention. Phase B's zero-findings fast-path now redirects to Phase D.5 instead of skipping straight to Mark done, ensuring the architecture gate is never bypassed.
